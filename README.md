## 🏢 About Perfect Printers

With over **20+ years of industrial experience** in commercial printing, **Perfect Printers** operates a full-spectrum offset printing and pre-press facility in the **Miraj MIDC Industrial Area (Sangli–Miraj Kupwad industrial corridor, Maharashtra 416410)**.

### Core Capabilities
* **Met-Pet Printing**: Premium substrate-level metallic luster and high-opacity white underprinting for cosmetics, confectionery, and luxury packaging.
* **UV Drip-Off Coating**: Simultaneous inline application of matte varnish and high-gloss spot UV for tactile textural depth.
* **Multicolor Commercial Offset**: High-speed multi-unit sheetfed printing with in-line densitometry and ultra-fine dot reproduction.
* **Thermal CTP Pre-Press**: Computer-to-Plate direct infrared laser imaging for microscopic sharpness and tight multi-color registration.

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/omiee-9108/perfect-printers.git

# Navigate to project directory
cd perfect-printers

# Install dependencies
npm install

# Run the local development server
npm run dev

# Build for production
npm run build
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
